# Chord Lab

日本語のコード進行試聴ツール。Web Audio APIのピアノ系合成音でブラウザ内だけで演奏します。音声サンプルや外部CDN、サーバー、APIキーは不要です。

## 現在の成果物：Phase 1

- Cmaj7 → Am7 → Dm7 → G7、120 BPM、各4拍、4/4
- 全体再生・停止・ループ、40〜240 BPM、各コード0.25〜32拍
- 再生中コード、拍、全体位置の表示、構成音と鍵盤の可視化
- コード名直接入力、メジャー／マイナー／7／maj7／m7／dim／aug／sus4／add9／オンコードなど
- 3つの進行プリセット、音量調整、レスポンシブUI
- 進行やBPM変更時に停止して先頭へ戻り、安全に再開
- 停止は発音中と予約済みの全ソースを取消。非表示タブ・音声中断時も停止

## 公開

GitHubの Settings → Pages → Build and deployment で **Deploy from a branch**、**main / (root)** を選択して保存してください。ソースはビルド不要の静的ファイルです。

## ローカル開発

Node.js 22以上で `npm test`。依存パッケージのインストールは不要です。ローカル表示時は静的HTTPサーバーから配信してください。

- `theory.js`: コード解析、MIDI音高、データ検証
- `audio.js`: 音声生成、短い先読みスケジューラ、ソース取消と非同期競合対策
- `app.js`: UIとユーザー操作
- `style.css`: ダークUIとレスポンシブ表示

コードの `symbol` と実際に演奏する `notes` を分離しています。カスタムボイシングを将来追加しても全体再生は `notes` をそのまま使用します。

## 確認状況と次の段階

Nodeによる解析・スケジューラの自動テストは実施済みです。テストはAudioContextの模擬実装を使い、実際のブラウザ発音確認を代替するものではありません。ブラウザでPhase 1の発音・停止・BPM・ループを検証してからPhase 2へ進む方針です。

未実装：コード追加／削除／複製／並べ替え、単独試聴UI、移調、保存・読み込み、転回形、ボイシング編集、ピアノロール、音色切替、アルペジオ、ストローク、MIDI出力、声部進行分析・最適化。

ピアノ系音色は合成音です。ブラウザのユーザー操作制限により、音声開始には再生ボタンが必要です。スマートフォン実機の動作確認は未実施です。
