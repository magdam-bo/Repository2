# Chord Lab

日本語のコード進行試聴ツール。Web Audio APIのピアノ系合成音でブラウザ内だけで演奏します。音声サンプルや外部CDN、サーバー、APIキーは不要です。

## 実装済み

- 全体再生・停止・ループ、40〜240 BPM、各コード0.25〜32拍
- Cmaj7 → Am7 → Dm7 → G7、初期120 BPM、各4拍、4/4
- 再生中コード・拍・全体位置、実際のWeb Audio出力レベル、88鍵の構成音表示
- コード名直接入力、追加・削除・複製・前後移動、単独試聴、半音移調
- 転回形・オクターブ、構成音単位の音高・追加・削除、ベース最低音、オープン／クローズ
- 音高を切り替えるピアノロール（各コードの全音は同時発音）
- ボイシングを含むブラウザ内保存・読込、JSON書出・読込
- 3つのプリセット、音量調整、日本語ダークUI、レスポンシブ表示
- 編集や進行・BPM変更時に全ソースを停止し、先頭へ戻って安全に再開

## 公開

GitHubの Settings → Pages → Build and deployment で **Deploy from a branch**、**main / (root)** を選択して保存してください。ソースはビルド不要の静的ファイルです。

## ローカル開発

Node.js 22以上で `npm test`。依存パッケージのインストールは不要です。ローカル表示時は静的HTTPサーバーから配信してください。

- `theory.js`: コード解析、MIDI音高、データ検証
- `audio.js`: 音声生成、短い先読みスケジューラ、ソース取消と非同期競合対策
- `app.js`: UIとユーザー操作
- `style.css`: ダークUIとレスポンシブ表示

コードの `symbol` と実際に演奏する `notes` を分離しています。カスタムボイシングを将来追加しても全体再生は `notes` をそのまま使用します。

## 確認状況と残りの機能

Node自動テスト8件を実行。Phase 1公開版をChromeで操作し、再生・停止、BPM40/240、拍数変更、ループ継続と解除、自然終了後の再再生を確認しました。AnalyserNodeで実際の音声出力の非ゼロ信号を確認しています。人間の耳での音質評価とスマートフォン実機の発音確認は未実施です。

未実装：音色切替、アルペジオ、ストローク、MIDI出力、声部進行の分析・最適化。ピアノロールは構成音の編集用で、音ごとに異なる開始時刻や長さを指定する機能はありません。

ピアノ系音色は合成音です。音声開始にはユーザーの再生操作が必要です。非表示タブや音声中断時は停止します。保存はこのブラウザ内のみです。JSON書出で別端末へ移せます。
